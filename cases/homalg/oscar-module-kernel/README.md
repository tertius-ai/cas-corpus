# Kernel of a polynomial-module map

Over `R=Q[x,y,z]`, define `a:R^3 -> R^2` by

```text
e1 |-> y f1,
e2 |-> (x+y) f1 + y f2,
e3 |-> z f2.
```

Compute the kernel and prove that it is generated by

```text
z(x+y)e1 - yz e2 + y^2 e3.
```

Noether verifies the displayed vector maps to zero, computes the kernel by a
module Groebner-basis calculation, and certifies equality with the principal
submodule generated by that vector.
