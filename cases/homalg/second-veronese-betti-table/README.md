# Betti table of the second Veronese surface

Let `R=Q[a,b,c,d,e,f]`. The second Veronese surface in `P^5` is defined by the
six `2 x 2` minors of

```text
[a b c]
[b d e]
[c e f].
```

Present its coordinate ring as a graded `R`-module, compute a minimal free
resolution, and certify the nonzero Betti entries

```text
beta_(0,0)=1, beta_(1,2)=6, beta_(2,3)=8, beta_(3,4)=3.
```

This exactly reproduces the small `nu_2(P^2)` table printed in the paper's
appendix. The much larger sixth-Veronese table that motivated the original
intake record remains a performance case.
