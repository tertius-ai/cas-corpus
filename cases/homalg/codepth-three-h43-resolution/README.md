# A codepth-three class H(4,3) example

Over `Q[x,y,z]`, resolve

`Q[x,y,z]/(z^2, y^3, x*y^2, x^2*y, x^3)`.

Noether verifies a minimal graded free resolution with total Betti numbers
`(1,5,7,3)`, including the graded shifts. This is the ordinary commutative-
algebra computation underlying the source's classification as Tor-algebra
class `H(4,3)`; the multiplicative Tor structure itself is not claimed.
