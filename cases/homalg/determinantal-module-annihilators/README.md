# Determinantal module annihilators

The source starts from the Hankel-like matrix

```text
[x3 x2 x1]
[x2 x1 x0]
[x1 x0  0]
```

and the ideals generated by its displayed minors. It ultimately identifies
the determinantal ideal
`p1=(x1*x3-x2^2,-x0*x3+x1*x2,-x0*x2+x1^2)` and the linear ideal
`p2=(x0,x1,x2)` as annihilators of constructed modules.

The adaptation verifies the two determinant formulas, reconstructs the final
cyclic presentations and asks Noether for their annihilators. It also encodes
the source submodule calculation as the equivalent colon ideal
`(f,g,h):q=p2`, and certifies the linear component as primary.
