# A rational quartic over F32003

Resolve the homogeneous coordinate ring over `F_32003` defined by

`(x*y-w*z, y^3-x*z^2, w*y^2-x^2*z, x^3-w^2*y)`.

Noether verifies a minimal graded resolution with total Betti numbers
`(1,4,4,1)` and its non-pure shifts. The source continues from this curve to
global extension modules; that sheaf-theoretic computation is not claimed.
