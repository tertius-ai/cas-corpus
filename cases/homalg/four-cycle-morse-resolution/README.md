# The edge ideal of a four-cycle

Resolve `Q[w,x,y,z]/(w*x, x*y, y*z, w*z)`, the ordinary edge-ideal
calculation beneath a source example for discrete Morse resolutions.

Noether verifies minimality and the graded Betti entries
`1, 4 t^2, 4 t^3, t^4`, hence total ranks `(1,4,4,1)`. The case deliberately
does not claim to reconstruct the paper's Morse matching.
