# Compute Hom and Ext of presented polynomial modules

Reconstruct the two `Q[x,y,z]` modules in the archived Hom worksheet. Noether computes a 7-generator/7-relation presentation for `Hom(L,K)`, a 3-generator/9-relation presentation for `Ext¹(L,K)`, and proves `Ext²(L,K)=0`; the Hom annihilator is also certified exactly.
