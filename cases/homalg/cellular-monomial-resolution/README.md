# A monomial ideal from a cellular-resolution example

Over `Q[w,x,y,z]`, resolve

`Q[w,x,y,z]/(y*w, x*y*z, x^2*y, z^4*w)`.

Noether verifies a minimal resolution with total Betti numbers `(1,4,4,1)`
and records its non-pure graded shifts. This isolates the algebraic output of
the source example; a supporting labeled cell complex is not constructed.
