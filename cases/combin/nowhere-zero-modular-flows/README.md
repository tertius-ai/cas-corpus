# Nowhere-zero modular flows

The source validates its QUBO formulation against direct finite-graph flow
counts. This bounded translation keeps the mathematics: it enumerates nonzero
edge labels, checks incidence conservation in `Z/kZ`, obtains zero and six
flows on `K_4` for `k=3,4`, and proves the six-count is unchanged across all
64 orientations. It also checks the two smallest theta-graph counts.
