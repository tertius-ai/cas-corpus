# A four-element matroid from its bases

Let a rank-two matroid on `{1,2,3,4}` have bases

```text
12, 13, 14, 23, 24.
```

Recover its circuits and rank function. The source prints the three circuits
`34`, `123`, and `124`. The calculation also records the Tutte polynomial as
an additional exact invariant, without attempting the source's later
realization-space computations.
