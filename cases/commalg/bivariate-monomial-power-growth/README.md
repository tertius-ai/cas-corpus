# Bounded powers of a bivariate monomial ideal

For `I=(y^2, x^2*y, x^3)` in `Q[x,y]`, form `I^(3+ell)` for
`0 <= ell <= 12` and minimize the monomial generating set of every power.

Noether finds `7+2*ell` minimal generators throughout this bounded range.
The case exposes the exact finite calculation behind the source's study of
large powers; it is not a proof of the paper's general eventual formula.
