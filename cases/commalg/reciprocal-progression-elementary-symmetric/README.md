# An exceptional reciprocal-progression symmetric value

For the reciprocals `1`, `1/2`, and `1/3`, compute the second elementary
symmetric function

`1*(1/2) + 1*(1/3) + (1/2)*(1/3)`.

Use the standard generating polynomial: this value is the coefficient of
`t^2` in

`(1+t)(1+t/2)(1+t/3)`.

Exact polynomial arithmetic gives the exceptional integer value `1`. The case
is a bounded instance of the source's computer-assisted search, not a claim to
translate its proof or its full parameter sweep.
