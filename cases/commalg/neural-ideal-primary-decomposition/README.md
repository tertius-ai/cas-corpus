# Primary-decompose a three-neuron neural ideal

For the binary neural code `C={001,010,110}`, the five excluded binary words
define five indicator pseudomonomials in `F_2[x0,x1,x2]`. The source reports
that their ideal is

```text
(x2 + 1, x1, x0) intersection (x2, x1 + 1).
```

The case rebuilds the neural ideal from the excluded words, admits the two
published components to Noether's certified decomposition path, separately
certifies each component as primary, and verifies both ideal containments.
