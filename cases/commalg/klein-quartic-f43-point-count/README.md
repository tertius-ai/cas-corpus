# The Klein quartic over F43

In projective two-space over `F_43`, count the rational points on

`x^3*y + y^3*z + z^3*x = 0`.

Noether's deterministic four-shard enumeration checks all 1,893 normalized
projective candidates and certifies exactly 80 points. This is a scoped finite-
field computation from the source, not its later Riemann--Roch or representation
theory calculations.
