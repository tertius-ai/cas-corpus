# A seven-torsion polynomial certificate

The source's basic Magma verification defines six explicit polynomials in
`mu`. Noether checks its degree-48 identity
`N7(N7-1728T7)=A7^3 B7^3 R7^2` exactly and verifies that `A7*B7` is
squarefree through its factorization. The later hyperelliptic Chabauty work is
deliberately outside this bounded case.
