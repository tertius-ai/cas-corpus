# Colon witnesses for a monomial associated prime

In `Q[x1,x2,x3,x4,x5,x6]`, let

`I = (x1*x3^5, x1*x6^8, x2*x5^3, x2*x4^4, x1^5*x4^2)`.

Each of the four monomials

`x3^5*x4^4`, `x3^5*x5^3`, `x6^8*x4^4`, and `x6^8*x5^3`

is a witness for the same colon ideal. Compute all four colons and verify that
each is the prime ideal `(x1,x2)`.
