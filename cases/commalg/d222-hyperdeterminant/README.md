# Recover the 2 x 2 x 2 hyperdeterminant

Let `f` be the generic trilinear form with eight independent coefficients.
The source eliminates `x1,x2,x3` from the ideal generated by `f` and its
three first partial derivatives. The resulting coefficient condition is
Cayley's twelve-term quartic hyperdeterminant.

This translation constructs that critical ideal over the rationals, performs
the same lexicographic elimination, and checks the unique Gröbner generator
term-for-term against the displayed quartic. The case is only the exact
elimination certificate; it does not reproduce the source's surrounding
polyhedral discussion.
