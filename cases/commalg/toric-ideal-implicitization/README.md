# Toric implicitization by elimination

The CoCoA examples compute toric ideals for exponent rows `(1,2,3)` and
`(3,4,5)`, then implicitize `(s^2,st,t^2)`. Noether constructs the graph
ideals, eliminates the parameters, and proves equality with explicit binomial
presentations, including `y^2-xz` for the quadratic Veronese map.
