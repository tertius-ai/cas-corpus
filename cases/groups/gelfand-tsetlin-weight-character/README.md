# A GL(3) character from Gelfand--Tsetlin data

For the partition `(3,1,1)`, enumerate semistandard tableaux with entries at
most three and collect their contents. These contents are the weights of the
corresponding polynomial representation of `GL(3)`.

The source obtains six lattice points from the associated Gelfand--Tsetlin
polytope. Noether recovers six tableaux and the six weight monomials

```text
(3,1,1), (2,2,1), (2,1,2), (1,3,1), (1,2,2), (1,1,3),
```

each with multiplicity one, and independently verifies the Weyl dimension.
The source's Ehrhart polynomial is not claimed by this scoped translation.
