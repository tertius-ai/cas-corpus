# Compute the combinatorial automorphism group of the four-cube

An OSCAR notebook prints four permutations of the eight facets of the
four-dimensional cube and reports that they generate a group of order 384.
Construct that permutation group exactly, check transitivity, and recover its
abelianization.

The permutations are entered independently from the saved notebook output;
no OSCAR or GAP code is copied or run.
