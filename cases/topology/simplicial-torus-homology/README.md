# Integral homology of a triangulated torus

The SimplicialHomology examples include a seven-vertex, fourteen-triangle
triangulation of the torus. Reconstruct it in Noether, check its face counts
and Euler characteristic, and recover `H_0 = Z`, `H_1 = Z^2`, and `H_2 = Z`.

Only the published facet data are transcribed; the source package is not run.
