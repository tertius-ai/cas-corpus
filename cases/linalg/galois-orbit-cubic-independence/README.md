# Test cubics on a finite-field Galois orbit

In `GF(3¹⁰) = GF(3)[a]/(a¹⁰+a⁴+a+1)`, evaluate the ten degree-three plane monomials at `(1:a:aᵏ)`. Writing the values in a base-field basis produces a 10-by-10 matrix. Its determinant vanishes for `k=0,…,7` and equals one for `k=8,9`, reproducing the ancillary calculation.
